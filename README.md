# 🍷 Análisis del Dataset de Vinos

Este proyecto fue realizado para una materia practica de la carrera el cual documenta el análisis integral de un dataset de vinos, orientado a brindar información clave e *insights* de negocio para comerciantes y productores del sector vitivinícola. El trabajo se desarrolló a lo largo de 4 etapas consecutivas:


### 📌 Etapa 1: Aplicación de la Ciencia de Datos en la Industria
- **Descripción:** Introducción y análisis conceptual sobre cómo la ciencia de datos aporta valor a comerciantes y productores de vinos.

### 🧹 Etapa 2: Preprocesamiento y Limpieza de Datos
- **Descripción:** Limpieza del dataset, tratamiento de datos faltantes y análisis exploratorio inicial de variables.

### 🗄️ Etapa 3: Análisis de Datos con SQL
- **Descripción:** Consultas SQL estructuradas para responder preguntas específicas sobre el dataset.

### 📊 Etapa 4: Análisis Exploratorio Final, Visualización y Conclusiones
- **Descripción:** Evaluación del comportamiento de variables de interés, generación de gráficos explicativos, hallazgos clave y conclusiones estratégicas para la toma de decisiones comercial y productiva.


## 🧰 Tecnologías y Herramientas
- **Lenguajes:** Python, SQL
- **Librerías de Python:** Pandas, NumPy, Matplotlib, Seaborn
- **Visualización y Documentación:** Informes en PDF
